# Product Brief: Developer Portfolio & China Sourcing Demo Platform

## Project Overview
Высококонверсионный сайт-визитка / интерактивное портфолио веб-разработчика (Михаил Соболев, Telegram: @whhwheqkkwk, GitHub: torch817) с живым интерактивным демо сервиса заказа товаров из Китая (1688 / Taobao / Poizon).

## Definition of Done (DoD) Criteria
1. **Стек & Архитектура**: React 18/19, Vite, TypeScript, Tailwind CSS, Lucide React, shadcn/ui паттерны, Magic UI анимация фона/сетки. Готовность к сборке (`npm run build`) и локальному запуску (`npm run dev`).
2. **Главная страница (`/`)**:
   - Hero-секция с четким позиционированием: имя «Михаил Соболев», роль «Веб-разработчик: сайты и сервисы для приёма заказов», подзаголовок «Делаю быстрые, понятные сайты под задачу: от макета до запуска», кнопки «Посмотреть демо» и «Написать мне».
   - Секция проектов (2 карточки: «Демо: сервис заказов из Китая» с переходом на `/demo`, «Этот сайт-визитка»).
   - Секция навыков: 3 группы («Фронтенд», «Бэкенд и данные», «Запуск»).
   - Секция «Обо мне»: 3-4 строки делового спокойного текста.
   - Секция контактов: Telegram @whhwheqkkwk, Email, GitHub torch817, работающая форма с валидацией и Toast-уведомлением.
   - Футер.
3. **Страница Демо (`/demo`)**:
   - Интерактивная форма заказа: поле ввода URL (валидация ссылок), количество, цена в юанях (¥ CNY), комментарий.
   - Динамический калькулятор стоимости: цена в CNY × курс + комиссия (%) + доставка ($/кг -> ₽). Прозрачная разбивка с формулами.
   - Кнопка «Оформить заказ»: отправка заказа с анимацией, Toast об успешном оформлении, моментальное добавление в таблицу заказов.
   - Таблица «Мои заказы»: список тестовых заказов с цветными бейджами статусов (`Новый`, `Выкуплен`, `На складе в Гуанчжоу`, `В пути (Карго)`, `Доставлен`).
4. **Serverless & Уведомления**:
   - Vercel Serverless функция `/api/order.ts` для отправки уведомлений в Telegram Bot при наличии `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env`.
   - Грациозный fallback в UI при отсутствии переменных окружения.
5. **Качество & UX**:
   - Переключатель темной и светлой темы (Dark mode по умолчанию).
   - 100% мобильная адаптивность.
   - Русскоязычный интерфейс.
   - `.env.example`, `README.md` с пошаговыми инструкциями запуска и деплоя на Vercel.
