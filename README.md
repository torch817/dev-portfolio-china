# Портфолио Михаила Соболева

Сайт веб-разработчика с интерактивным демо сервиса заказа товаров из Китая. Это демонстрационный проект для знакомства с интерфейсом и кодом, а не действующая система закупок.

## Что посмотреть

- `/` — портфолио: проекты, стек и контакты.
- `/demo` — форма заказа по ссылке на 1688, Taobao, Tmall или Poizon/Dewu, калькулятор стоимости, выбор доставки и журнал заказов.

Расчёт ориентировочный: курс запрашивается через `/api/rate` с резервным значением при недоступности источника. Примеры товаров и заказов вымышленные. Черновик и журнал хранятся только в `localStorage` браузера; общего хранилища и реального оформления заказа нет. `/api/order` проверяет запрос и может отправить уведомление в Telegram, если заданы переменные окружения. Без них API работает в демо-режиме. Не вводите настоящие персональные данные.

## Стек

React 18, TypeScript, Vite, Tailwind CSS; serverless-функции Vercel для `/api/health`, `/api/rate` и `/api/order`.

## Локальный запуск

```bash
npm ci
npm run dev
```

Для проверки перед публикацией:

```bash
npm run build
npm run test:api
npm run test:chart
npm run test:utils
npm run check:budgets
npm run test:e2e
```

E2E-тестам нужен установленный браузер Playwright. Локальный `vite`/`vite preview` обслуживает интерфейс; serverless API запускается в окружении Vercel, а не в обычном Vite-сервере.

## Публикация

Проект настроен для Vercel: сборка `npm run build`, результат — `dist`, правила маршрутизации — `vercel.json`. Привяжите этот репозиторий к своему проекту Vercel и выпустите production deployment. Переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` необязательны и нужны только для уведомлений; задавайте их в настройках Vercel, не в репозитории. Публикация сама по себе не превращает демо в сервис приёма реальных заказов.
