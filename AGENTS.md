## Project Overview
High-converting developer portfolio & interactive China sourcing e-commerce demo application for Mikhail Sobolev (Telegram: @whhwheqkkwk, GitHub: torch817).

## Tech Stack
- Frontend: React 18, Vite, TypeScript, Tailwind CSS, Lucide React icons
- UI Primitives: shadcn/ui inspired (Button, Card, Input, Textarea, Badge, Table, Toast)
- Animation: Magic UI Dot-Grid / Gradient mesh
- Backend: Vercel Serverless Function (/api/order.ts) with Telegram Bot notifications
- Hosting: Vercel ready

## Build & Test Commands
```bash
npm run dev
npm run build
npm run preview
```
